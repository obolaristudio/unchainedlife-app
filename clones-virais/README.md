# Clones virais

Pasta de trabalho para recriar Reels virais (estrutura, ritmo, gancho) com o conteúdo da Obolari Academy.

## Ferramentas
- Skill `hypit` (`.claude/skills/hypit`): direção e produção do vídeo a partir de uma referência.
- Skills `reverse-any-video`, `efeitos-virais`, `video-effects`, `obolari-instagram`.

## Pré-requisitos para gerar mídia
- Programa da Hypit: `npm install -g @hypit/hypit` (verificar com `hypit version`).
- Conta Hypit ou de provedor parceiro conectada (créditos de geração).

## Regra
Clonar o formato, nunca a mídia, a marca ou o texto de outro criador.
